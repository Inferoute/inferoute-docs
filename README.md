# Inferoute Documentation

Source for the Inferoute user docs at **https://docs.inferoute.com**. Built with [Zensical](https://zensical.org) and hosted on Cloudflare Pages.

## Write and preview

Pages live in `docs/`. The sidebar comes from `nav` in `zensical.toml`.

```bash
uvx zensical@0.1.1 serve          # live preview at http://localhost:8000
uvx zensical@0.1.1 build --strict # what CI runs; fails on broken links
```

Style: [documentation-style.md](documentation-style.md). Use generic examples (**inferoute-cluster1**, not real cluster names).

Callouts:

```markdown
!!! warning

    Body text, indented four spaces.
```

## Structure

- `docs/index.md` — Overview (site home)
- `docs/getting-started/` — requirements, sign up, install
- `docs/consumer/` — API usage, spending caps, routing
- `docs/provider/` — provider dashboard
- `docs/provider-client/` — provider client reference
- `docs/api/` — API reference page (Scalar) and `openapi.json`
- `docs/_redirects` — old GitBook URLs to current pages
- `docs/stylesheets/inferoute.css` — theme, matching inferoute-web (`DESIGN.md` there)
- `overrides/.icons/inferoute/` — the Inferoute mark used as the logo

## Deploy

`.github/workflows/deploy.yml` builds on every push and pull request.

- Push to `main` deploys to production.
- A pull request deploys a preview and posts its URL on the PR.

Needs, in this repo's Actions settings:

- Secret `CLOUDFLARE_API_TOKEN` — Cloudflare API token with **Account › Cloudflare Pages › Edit**.
- Variable `CLOUDFLARE_ACCOUNT_ID` — the Cloudflare account that owns the `inferoute-docs` Pages project.

## API reference

`docs/api/openapi.json` is generated by the **API docs** workflow in inferoute-node. When the spec changes, that workflow commits the new file here with a deploy key ("inferoute-node API spec"), and this repo's deploy runs. Do not edit `openapi.json` by hand.
